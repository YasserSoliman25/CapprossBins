# CapprossBins — Interactive WOE & IV Binning for Credit Risk Scoring

An interactive web tool for credit risk data binning, Weight of Evidence (WoE), and Information Value (IV) optimization. Built for credit scoring professionals, data scientists, and financial institutions.

## What is CapprossBins?
CapprossBins is a comprehensive, accessible alternative to heavy enterprise software (like SAS or FICO) and programmatic Python libraries (like OptBinning or scorecardpy). It provides an intuitive, interactive web interface for building transparent credit risk models, performing WOE segmentation, and calculating Information Value without writing code.

## Key Features
- **Interactive WOE Binning**: Manually adjust bins with monotonic constraints.
- **IV Calculation**: Feature selection based on Information Value.
- **Model Stability**: Monitor Population Stability Index (PSI).
- **Credit Scorecard Development**: Transparent models with SHAP explainability.
- **Regulatory Compliance**: Support for Basel and IFRS 9 standards.
- **Model Governance**: Complete audit trails for risk model adjustments.

## Scope

CapprossBins is an analytical tool. Its outputs are modelling aids for qualified
practitioners — not credit advice, not a lending decision, and not a certification
of regulatory compliance. References to Basel or IFRS 9 describe the analytical
support provided, not a warranty that any model built with it satisfies a
supervisory requirement. Model validation, governance and fair-lending testing
remain yours.
